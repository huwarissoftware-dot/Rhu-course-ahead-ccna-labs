# CCNA 200-301 v2.0 — Syllabus Coverage Checklist

Source: Cisco official exam topics (200-301 CCNA v2.0). Every row must have at least one lab in the app — nothing missed. All labs FREE / UNLOCKED.

## 1. Network Infrastructure and Connectivity (25%)
- [ ] Cable & interface issues (speed/duplex mismatch, errors) — troubleshooting lab
- [ ] IPv4 addressing, assignment & subnetting (public/private) — addressing + subnetting labs
- [ ] IPv6 addressing & prefix sizing — IPv6 labs
- [ ] Wireless principles (bands, channels, security) — concept/quiz module
- [ ] Wired/wireless client connectivity — PC ncpa.cpl + ping labs (Windows)
- [ ] DHCPv4 client, server & relay on IOS — NAT/DHCP category labs

## 2. Switching and Network Access (25%)
- [ ] Switch-to-switch & switch-to-router connectivity, trunks (802.1Q)
- [ ] EtherChannel / LACP port-channel
- [ ] SVI (switch virtual interface) + management VLAN & default gateway
- [ ] Edge ports for PC / printer / AP / VoIP phone
- [ ] CDP & LLDP documentation check
- [ ] Show commands, ping, traceroute, logs — troubleshooting
- [ ] Rapid PVST+: root bridge primary/secondary, PortFast, BPDU/root/loop guard

## 3. IP Routing (20%)
- [ ] Read a routing table (prefix, AD, metric, next hop, default route)
- [ ] Static routing: default / network / host / floating
- [ ] Single-area OSPFv2 + OSPFv3: neighbors, DR/BDR, router ID
- [ ] FHRP (HSRP/VRRP) status — concept lab

## 4. Network Services and Security (20%)
- [ ] Local users + AAA client concepts (TACACS+/RADIUS)
- [ ] Secure file transfer (SFTP/SCP) concept
- [ ] NAT/PAT on IOS routers
- [ ] DNS records (A, AAAA, CNAME, MX, NS, PTR) — concept + lab
- [ ] IPsec VPN concepts (remote access & site-to-site)
- [ ] IPv4 ACLs: standard, extended, numbered, named
- [ ] Layer 2 security: DHCP snooping, DAI, storm control, RA guard, port security

## 5. AI and Network Operations and Management (10%)
- [ ] Agentic AI in network operations — concept module
- [ ] Prompting a generative AI for netops — concept module
- [ ] Management approaches (device/cloud/controller/automation/IaC)
- [ ] SNMP purpose — concept lab
- [ ] Configuration management (Ansible) — concept lab
- [ ] Syslog: severity levels & facilities — concept lab

## App extras (matching/better than reference sites)
- [ ] Free Sandbox (add devices, cable them, test ping)
- [ ] Troubleshooting helpdesk tickets (shutdown port, mask error, wrong gateway, VLAN isolation, duplicate IP + more)
- [ ] Practice quizzes: 6 domain modules + final mixed assessment — all unlocked
- [ ] Bonus labs beyond CCNA core: EIGRP basics, BGP neighbors, GRE tunnel, serial WAN/PPP
- [ ] Capstone: build a full small office network from zero
